# Makori Samuel Momanyi - Information Technology Student Website

This is a simple, modern IT student portal website built for Makori Samuel Momanyi, a Bachelor of Information Technology student at Kisii University, Kenya.

## Features
- Responsive design for mobile and desktop
- IT-focused sections: About, Study Areas, Skills, Projects, Resources, and Contact
- Admin page for simple editing and content management
- Easy to customize and expand with more content

## How to view the website
Open the `index.html` file directly in a browser or host the project in GitHub Pages.

## Admin access
Open the admin page in your browser:

`admin.html`

Default admin password:

`MakoriIT2026!`

After logging in, you can edit the website content and save it in the browser.

## Deploy on GitHub Pages
1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Under "Build and deployment", select:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5. Save.
6. Your website will be published and you will get a GitHub Pages URL.

## Editing content
- Open `admin.html`
- Login using the admin password
- Update the text fields and save
- The site will update instantly in the browser using local storage

## Notes
This is a front-end site that is easy to edit and ideal for a student portfolio or academic information portal.

By default, it is set up with content related to Information Technology and can be expanded with more topics, courses, or project work.

You can replace the placeholder email and content with your own details at any time.
